## 一、Telegram是什么？

Telegram是一款面向全球用户的即时通讯软件，由Pavel Durov和Nikolai Durov创办，开发团队目前主要位于迪拜。和国内常见的聊天软件相比，Telegram最大的特点不是单纯能聊天，而是支持跨平台使用、云端同步、大型群组和频道订阅，同时也比较重视隐私和账号安全。Telegram官方也把它定位为一款注重速度和安全性的云端通讯应用。

简单来说，Telegram不只是一个普通聊天软件。它既可以用来和联系人一对一聊天，也可以用来加入群组、订阅频道、发送文件、查找用户，还可以使用各种机器人完成翻译、提醒、文件管理和信息查询等操作。

Telegram和普通通讯软件的区别，主要体现在几个方面。第一，它支持多设备同时登录。用户可以在手机、平板、电脑和网页端登录同一个Telegram账号，聊天记录会在不同设备之间自动同步，不需要手动迁移聊天记录。第二，Telegram的群组容量比较大，单个群组最高可以支持20万名成员，比较适合用来做社群交流、项目讨论、兴趣分享和信息发布。第三，Telegram支持频道功能，频道更像一个单向的信息发布工具。用户订阅频道之后，就可以接收频道管理员发布的内容。

另外，Telegram还有一个很重要的特点，就是支持通过用户名查找和联系其他用户。也就是说，你不一定要把自己的手机号码直接发给别人，对方也可以通过你的用户名找到你。对于不想公开手机号的用户来说，这个功能会更方便。

不过需要注意，Telegram并不是所有聊天都默认使用端到端加密。普通私聊、群组和频道都属于云端聊天，聊天内容可以在多个设备之间同步。只有单独创建的Secret Chat，也就是“秘密聊天”，才会使用端到端加密，而且秘密聊天只能在创建该聊天的设备上查看。

所以，如果只是日常聊天、加群、订阅频道或者接收信息，普通聊天功能基本够用。如果你要发送比较敏感的内容，建议单独使用秘密聊天，同时也要保护好自己的账号、设备和验证码。

注册Telegram账号时收不到验证码，是一个很常见的问题。如果你遇到这种情况，不要一直点击发送验证码，也不要在短时间内频繁更换手机号码。这样做不一定能解决问题，反而可能触发Telegram的安全限制。如果你一直收不到验证码，可以按照下面的顺序逐项排查。

* 检查你填写的手机号码格式

首先检查国家或地区代码是否正确，并确认手机号码有没有多写、少写或者输错数字。Telegram要求用户使用完整的国际号码格式。如果国家区号选错了，或者手机号码格式不正确，验证码就可能无法正常发送。

* 检查已登录Telegram的设备

如果这个手机号码以前注册过Telegram，验证码可能不会通过短信发送，而是会发送到其他已经登录的Telegram客户端中。你可以检查旧手机、平板、电脑端，以及同一部手机上的其他Telegram客户端，看看有没有收到Telegram官方对话发来的验证码。

* 等待当前页面的倒计时结束

Telegram发送验证码后，页面一般会显示倒计时。你应当先等待倒计时结束，然后再使用页面提供的重新发送选项。不要在倒计时还没有结束时反复操作，也不要连续请求验证码。连续请求验证码可能会触发Telegram的安全限制，导致验证码暂时无法继续发送。

* 检查你手机的短信拦截功能

你可以检查手机里的垃圾短信、骚扰拦截记录和安全软件记录，确认验证码短信有没有被系统自动拦截。如果你的手机号码无法接收国际短信，也可能收不到Telegram验证码。遇到这种情况时，可以向手机运营商确认这个号码是否支持接收国际短信。

如果Telegram客户端版本太旧，可能会出现登录页面异常、验证码页面无法刷新，或者客户端连接失败等问题。建议你先卸载来源不明的Telegram客户端，然后通过Telegram官网、Google Play或者App Store重新安装最新版本。

* 检查你当前设备的网络连接

如果Telegram客户端一直显示Connecting，说明客户端可能没有正常连接到Telegram服务器。你可以重新连接网络，切换到更稳定的网络环境，然后关闭并重新打开Telegram客户端，再尝试注册。

如果你在短时间内重复提交手机号码、频繁更换设备，或者连续请求验证码，都可能触发Telegram的临时安全限制。如果页面出现Too many attempts、Please try again later或者类似提示，就不要继续反复尝试了。这个时候应当先停止操作，等限制解除后再重新尝试。

* 联系Telegram的官方支持

如果手机号码格式正确，Telegram客户端也可以正常连接，但长时间仍然收不到验证码，可以通过Telegram官方支持页面提交问题。提交问题时，建议写清楚完整国际号码、设备系统、Telegram版本、页面错误提示和问题发生时间。不要在公开群组里发布完整手机号码、验证码、恢复邮箱或者其他账号信息。

## 六、如何做好电报账号的安全设置？

Telegram注册成功后，不建议马上加入大量群组，也不建议马上联系陌生用户。最好先把账号安全设置好，尤其是两步验证、手机号可见范围、活跃设备和客户端锁定密码这些设置。这样后面再添加好友、加入群组或者订阅频道时，账号会更安全，隐私也更不容易泄露。

* 第一步：开启两步验证功能

开启电报账号两步验证的路径是：Settings→Privacy and Security→Two-Step Verification。进入两步验证页面后，设置一个独立密码，并绑定一个可以长期使用的恢复邮箱。开启两步验证后，新设备登录账号时，除了需要输入验证码之外，还需要输入两步验证密码。即使其他人拿到了你的手机验证码，也不能只靠验证码直接登录你的Telegram账号。

* 第二步：设置手机号可见范围

设置手机号可见范围的路径是：Settings→Privacy and Security→Phone Number。用户可以根据自己的使用需求，把“谁可以看到我的手机号码”设置为Nobody或者My Contacts。Nobody表示不让其他人看到你的手机号码，My Contacts表示只有你的联系人可以看到你的手机号码。如果你不希望陌生人看到你的手机号，建议把这个选项设置得更严格一些。

* 第三步：删除可疑的活跃设备

删除可疑活跃设备的路径是：Settings→Devices。有些Telegram客户端可能会把这个选项显示为Active Sessions。用户需要检查列表中是否存在陌生手机、陌生电脑、陌生浏览器，或者不认识的登录地点。如果发现可疑设备，应当立即终止对应会话，并修改两步验证密码。

* 第四步：设置客户端锁定密码

打开Privacy and Security页面后，可以找到Passcode Lock或者类似选项。启用客户端锁定密码后，即使其他人拿到了已经解锁的手机，也不能直接打开Telegram查看聊天记录。如果你的设备支持指纹识别或面容识别，也可以配合生物识别功能一起使用。

* 第五步：关闭同步手机通讯录

如果你不希望Telegram持续同步手机通讯录，可以进入隐私与数据相关设置，关闭联系人同步。关闭后，Telegram就不会继续同步你的手机通讯录。对于已经同步过的联系人数据，也可以在设置里进行删除。

* 第六步：创建一个公开用户名

打开Settings页面后，找到Username选项，即可创建公开用户名。公开用户名可以包含英文字母、数字和下划线。设置成功后，其他用户可以通过用户名搜索并联系你，不需要知道你的手机号码。不过，公开用户名也会出现在Telegram全局搜索结果中。只要对方找到这个用户名，就可能向你发送消息。因此，如果你不希望被陌生用户搜索到，也可以暂时不设置公开用户名。
